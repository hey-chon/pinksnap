## PinkSnap

Simple setup and local development guide.

## Requirements

- Node.js 20 or newer
- npm 10 or newer

Check your versions:

```bash
node -v
npm -v
```

## Install dependencies

From the project root:

```bash
npm install
```

## Run local server

Start the Vite development server:

```bash
npm run dev
```

The app will print a local URL in the terminal (usually http://localhost:5173).

## Other useful commands

```bash
npm run build      # production build
npm run serve      # preview production build locally
npm run typecheck  # TypeScript checks
```
